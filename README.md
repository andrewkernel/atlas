# Atlas

Research specification for a local-first, scientific-fidelity-aware ML compute optimizer.

**Status:** research in progress; no application or validated performance claims.

The central question is whether explicit experiment contracts and targeted verification help select useful memory-saving transformations without silently changing the experiment being studied.

Start with the [research index](docs/research/README.md). All benchmark results must distinguish executed experiments from proposals.
