# Atlas documentation

Start with the [executive assessment](research/00-executive-assessment.md). Atlas should proceed as a constrained empirical research project; broad novelty and scientific-preservation claims are not established.

- [Research index](research/README.md): findings, sources, actual probes and proposal.
- [Architecture](architecture/overview.md): components, data flow, API and security boundary.
- [Implementation plan](roadmap/implementation-plan.md): phases, dependencies, effort, hardware and risks.
- [Milestones](roadmap/milestones.md): evidence and stop/pivot gates.
- [First coding task and acceptance criteria](roadmap/mvp-acceptance-criteria.md).

The repository contains a research specification and small original probes. It does not contain a working Atlas application or a completed GPU/full-training study.
