# Post-study environment, source and asset reconciliation

The [read-only collector](../../../benchmarks/snapshot_post_continuation_environments.py) checks eight isolated profiles against their prior records: core, original CUDA, checker, planner, interop, telemetry, QA and plotting. [Full record](post-study-environments.json). Package versions/additional-distribution comparisons have no discrepancies. All 54 selected Python-source files match installed unsigned wheel RECORD entries. This is neither a signature, whole-package check nor contemporaneous attestation.

All eight pinned QA acquisition files retain their expected byte lengths/SHA256 values, including pretrained weights and training JSON. The prepared feature archive also retains its digest. All 23 reviewed TrainParity and 53 Rockmate-family source files match their existing review manifests. No old environment, model, dataset or reviewed source was modified by the continuation's installations/executions. This statement has the selected/version/byte scopes just described; uninspected native binaries are not thereby attested.

The QA-only post-study runtime read reports Torch 2.13.0+cu130, CUDA build 13.0 and cuDNN version integer 92000. It initializes a CUDA context despite running no model or training; the owned job is cleaned up. Other profile reads inspect metadata/source without explicitly importing ML packages. The post-study vendor utility reports RTX 3060, driver 595.95 and 12,288 MiB total memory. This differs in scope from Torch's CUDA-visible total and allocator peaks.

**Metadata gap retained:** the QA studies did not capture driver/cuDNN version separately inside each measured worker. The post-study readings are labeled as such and do not retroactively fill that requirement. Future production run manifests must capture those runtime/device fields at execution, with timing and scope. This is another reason the current artifacts are development evidence rather than a completed primary reproducibility/effectiveness study.

The separate plotting environment is Python 3.11.17 with 11 hash-pinned binary distributions, including Matplotlib 3.11.2. The CPU controller remains Python 3.12.10; the core project requirement was not changed to accommodate a renderer. Bundled plotting packages were unavailable, and a first resolver build-interpreter warning was resolved by choosing the existing 3.11 interpreter explicitly. The final locked environment and actual rendering versions are recorded. The separate environments are historical research scopes, not a requirement that every future MVP user install all eight.
