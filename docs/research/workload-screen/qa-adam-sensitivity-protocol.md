# Prospective reduced-BERT adaptive-update sensitivity control

Motivation: the completed dropout-zero three-feature control has small gradient differences but fails the frozen post-update tensor predicate. Isolate whether selected observed parameter differences are reproduced by the actual optimizer given those gradients. This is a diagnostic follow-up to a known result, not a held-out discovery or a tolerance adjustment.

One bounded owned job builds two fresh identical BERT QA states with the frozen encoder/head/feature recipe: rows [0,3), length 384, seed 2501/start RNG 2503, eager FP32, TF32 off, all 37 Dropout probabilities zero, no checkpoint. Execute one logical update each with full batch 3 or microbatch 2+1. Keep constant per-head feature normalization, fully accumulated clipping at norm 1, and original native AdamW lr 3e-5 / betas .9,.999 / eps 1e-8 / group decay .01 or zero / foreach and fused false. Retain initial parameters, post-clip gradients and post-update parameters in RAM, releasing GPU state between the two executions. Do not write full tensor snapshots.

From these outcomes choose the ten largest absolute post-update parameter differences using a frozen rule: at most the top three elements from each named parameter, then global sort by descending absolute difference, name and flattened index. Report selection explicitly as diagnostic, not an independent sample. For each selected component retain initial value, both gradients/updates, group decay and an ideal first-step AdamW scalar calculation. Analyze first/second moments and epsilon rather than attributing divergence to a first-difference label alone.

Replay the selected components through native CUDA FP32 vector AdamW with the original hyperparameters and matching decay groups. Compare to actual full-model component values; report absolute and ULP distances. A replay discrepancy beyond two representable steps blocks an unqualified claim that this replay isolates the selected update. Also replay eps 1e-6 and 1e-4, and plain SGD at lr 3e-5 with the matching decay groups, on these fixed gradients. These are counterfactual diagnostic methods, not contract-preserving candidate repairs. Equal-gradient pairs must produce equal replay outputs as a positive control. Do not replace the real-model predicate, alter the training study's epsilon or infer scientific quality from the replay.

Use a separately versioned supervisor derived from the tested job-boundary implementation with only this reviewed worker registered. Preserve the original supervisor and its earlier bound source identities. Apply the same 240 s / 8 GiB actual RSS / 12 GiB job commit / 4 GiB host available / 16 MiB log soft guards and verified group cleanup. All failure/partial outcomes remain recorded. Freeze source and protocol before execution. Successful selected-component replay does not establish an entire full-model causal explanation, exact arithmetic equivalence, logical-32 reference consistency, full training or QA quality.
