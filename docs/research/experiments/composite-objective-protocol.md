# Frozen composite-loss normalization control

Purpose: refine the proposed adapter's objective semantics using known arithmetic, not demonstrate a new checker defect. The QA library averages two independently normalized endpoint losses; a single example-count scaling is valid only under its declared denominator conditions. The actual resource screen has both endpoint labels valid for every feature, so this control does not allege its normalization is wrong.

Use core CPU Torch, float64, seed 2601, a 3-input/10-output linear map reshaped into two five-position logits, seven fixed examples and a 4+3 partition. Ignore index is 5. Compare full logical-batch objective against (a) sums divided by the respective global valid counts and (b) local head means weighted by microbatch example count/7. Three label cases: equal global counts but unequal local counts; unequal global head counts; all ignored for the start head in the first microbatch while its global count remains positive. Retain raw gradients, finite-health observations and one SGD update at lr .05 when the observed loss/gradients are finite. The diagnostic may differentiate an explicitly nonfinite local mean to observe whether finite gradients can coexist; an actual training runner must stop on required loss-health failure. Add an all-globally-ignored-head precondition-refusal control.

Separately use theta=[.4,-.2], x=seven equally spaced values in [-1.2,1.3], y=cos(1.7*x), weights=softplus(theta[0]*x+theta[1]), squared prediction errors, objective S(theta)/D(theta). Compare full autograd, deliberately detached D, and the sum of microbatch numerator/denominator gradients combined by the quotient rule. Central finite differences, step 1e-6, independently check the full derivative. Forward equality alone is insufficient. This is not an optimization proposed for arbitrary prediction-dependent training losses.

Finite pure-fixture positive gradient/update comparisons use rtol 1e-10, atol 1e-12. The deliberate errors must exceed 1e-3 in at least one gradient component; finite-difference error must be below 1e-8. These are controls for these float64 inputs, not QA GPU tolerances or scientific-equivalence margins. Preserve failures and nonfinite observations explicitly with null numeric fields; never emit NaN JSON.

Existing comparison primitives can receive a correctly authored logical-batch-normalized adapter. Do not assert their scalar loss interface is fundamentally unable to represent a composite loss, or that Atlas alone can enforce these conditions. Share the same objective facts with the baseline. No full BERT numerical relation, QA quality or independent human labels are established here.
