# Milestones and evidence gates

| Milestone | Required artifact | Gate |
|---|---|---|
| M0 Research handoff | Source register, competitor matrix, proposal, architecture and counterexamples | Present as conditional research plan; confirm novelty with advisor and closest-code review |
| M1 Baseline profile | One trusted synthetic adapter; complete logical-update JSON report; CPU fallback | Repeated timing/measurement sanity; resource-unavailable fields explicit; no optimizer yet |
| M2 First justified candidate | Native accumulation and pure-region checkpoint config with change record | Positive controls plus denominator, RNG, BatchNorm and update-clock negative cases |
| M3 Evidence pipeline | Finite candidate trial set, complete provenance and abstaining report | Stale/missing evidence cannot pass; process failure leaves inspectable artifacts |
| M4 Selection pilot | Resource-only, deterministic and composed-checker comparisons on disjoint pilot cases | If no incremental benefit, narrow/pivot before building optional UI/LLM |
| M5 Confirmation freeze | Reviewed dataset rights, benchmark revisions, labels, margins, sample count and budget | No changes to primary analysis after results; amendments marked exploratory |
| M6 Research result | Held-out decision outcomes, actual GPU resource trials, paired full-run evidence where affordable | Report unsupported tiers and inconclusive fidelity; separate measured savings from estimates |
| M7 Reproducible handoff | Advisor-facing findings, reproduction commands, artifact manifest and limitations | Someone else can inspect/reproduce the narrow claim; no guaranteed publication |

## Stop/pivot policy

- If the composed native+checker workflow is equally good, prioritize upstream fault cases/benchmark contribution.
- If verification costs exceed practical benefit, study budgeted checks or restrict scope; never remove required checks merely to create a favorable speedup.
- If most target workloads exceed memory through persistent state, checkpointing/accumulation cannot solve the motivating case; investigate offload as a separate phase or conclude the current MVP has limited reach.
- If independent labels or meaningful margins are unavailable, make a systems/semantic finding and leave scientific-outcome equivalence unverified.

No milestone has a promised calendar date. Effort ranges and dependencies are in the [implementation plan](implementation-plan.md).
